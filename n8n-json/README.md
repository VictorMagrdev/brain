# n8n-json

Carpeta para los JSON exportados de workflows de n8n (migración Evolution → WAHA).

- Un archivo por workflow: `CLARO_MOVIL-evolution-original.json`, `CLARO_MOVIL-waha.json`.
- Antes de guardar, quitar credenciales, API keys y tokens (usar marcadores).

Ver [Migración WAHA: CLARO_MOVIL](../Projects/Migracion-WAHA-CLARO_MOVIL.md).
